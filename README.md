# 🐍 Fundamental Booster – Personal Data Collector

## 📌 Project Overview

**Fundamental Booster** is a beginner-friendly Python project designed to strengthen fundamental Python programming concepts through an interactive **Personal Data Collector**.

The program collects basic information from the user such as **name, age, height, and favourite number**, and then displays the entered information along with its **data type** and **memory address**. It also calculates an approximate birth year based on the entered age.

## 🎯 Learning Objectives

This project helps beginners understand:

* Python variables
* User input using `input()`
* Type conversion using `str()`, `int()`, and `float()`
* Python data types
* The `type()` function
* Memory addresses using `id()`
* Basic arithmetic operations
* Formatted console output
* Interactive Python programs

## ⚙️ Features

* 👤 Accepts user's name
* 🎂 Accepts user's age
* 📏 Accepts user's height
* 🔢 Accepts user's favourite number
* 🔍 Displays the data type of each value
* 💾 Displays the memory address of each variable
* 📅 Calculates an approximate birth year
* 👋 Provides a simple goodbye message

## 🛠️ Technologies Used
